# Кристалл: не разбей!

HTML5-кликер для Яндекс Игр на чистом JavaScript (Canvas, без движков).

- **Тап** по кристаллу — растёт размер и добавляются трещины.
- **Тап во время вспышки** (раз в секунду) — двойной рост и без трещин («Идеально!»).
- **Трещины 100%** — кристалл разбивается, рост теряется.
- **Продать** — осколки за кристалл, растут чуть быстрее размера (`размер × (1 + √размер / 4) × множитель кристалла`).

## Магазин

Каждый следующий уровень дороже в 1.5 раза.

| Улучшение | Эффект за уровень | Цена 1-го уровня | Макс. |
|---|---|---|---|
| Клей | −10% трещин от тапа (множится) | 150 | 15 |
| Помощник | +1 к размеру в секунду, без трещин (пока игрок активен последние 20 с) | 250 | 25 |
| Широкий ритм | окно «Идеально» +40 мс (250 → 490 мс) | 180 | 6 |

| Кристалл | Множитель | Цена |
|---|---|---|
| Кварц «Искра» | ×1 | — |
| Рубин «Алое сердце» | ×2 | 900 |
| Изумруд «Лесной страж» | ×3,5 | 5 500 |
| Аметист «Звёздная пыль» | ×6 | 26 000 |

Управление на ПК: клик / Пробел — тап, `S` — продать, `M` — магазин, `Esc` — закрыть. Прогресс хранится в `localStorage`.

Файлы: `index.html`, `style.css`, `game.js`. Для загрузки в Яндекс Игры заархивируйте их в zip
(SDK подключается через `/sdk.js`, который платформа отдаёт сама).
